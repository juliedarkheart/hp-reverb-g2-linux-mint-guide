Before you start

The G2 needs both its DisplayPort connection and its USB connection. The first test should be boring: Mint Cinnamon on X11, a direct GPU connection, and the headset at 60 Hz.

Good first-test setup

Linux Mint 22.x, Cinnamon/X11, a recent AMD GPU or proprietary NVIDIA driver, and the G2 connected directly to the computer.

Do not change yet

Do not start with 90 Hz, Wayland, adapters, hubs, custom kernels, or several VR runtimes at once. Those can come later.

GPU matters. AMD is usually the easier route. NVIDIA can work, but the G2 has had direct-mode and 90 Hz problems that may need extra patches.

Quick hardware check

inxi -Gxx
cat /etc/linuxmint/info
lsusb | grep -Ei 'HP|Microsoft|03f0|045e|WMR'

If the last command prints nothing, fix the physical connection first: check the powered breakout box, reseat the cable, and try a rear motherboard USB port.

1. Install the Linux VR pieces

Open Terminal and run:

sudo apt update
sudo apt full-upgrade
sudo apt install \
  monado-service \
  libopenxr-loader1 \
  libopenxr-utils \
  xr-hardware \
  vulkan-tools \
  libvulkan1 \
  libusb-1.0-0 \
  git cmake ninja-build build-essential
If Mint cannot find monado-service or xr-hardware: do not add a random repository. Mint versions use different Ubuntu bases. Use the source-build instructions in the Reverb G2 Linux guide instead.

Reload USB permissions

sudo udevadm control --reload-rules
sudo udevadm trigger

Unplug and reconnect the headset. Never run Steam or Monado with sudo.

Check Vulkan

vulkaninfo --summary

It should identify the real GPU. If Vulkan fails, fix the graphics driver before continuing.

2. Start and test Monado

Try the packaged user service:

systemctl --user enable --now monado.service
systemctl --user status monado.service

If Mint has no service unit, launch it manually:

monado-service

Leave that terminal open while testing.

Test before launching a game

hello_xr comes from the OpenXR utilities package. If the command is missing, install it first:

sudo apt install libopenxr-utils

Then confirm it is available:

which hello_xr

If that prints a path, run:

hello_xr

If Mint cannot provide libopenxr-utils, use another OpenXR sample from the Monado or Reverb G2 project instead.

What should appear?

hello_xr generates its own test scene. Inside the headset she should see several colored cubes: one in front of her and others associated with the controllers. Head movement should change the view.

If the headset is still black: stop here and do not continue to Steam yet. That means the OpenXR/display path is not working. There is no separate test-image file to download. Check the physical DisplayPort connection, confirm Monado is running, and look at the NVIDIA/AMD and DRM diagnostics below.

If the app opens on the monitor but the headset is blank, try the Vulkan renderer explicitly:

hello_xr -g Vulkan

If that option is rejected, run hello_xr --help to see the graphics option spelling supplied by that package.

Physical verification is required. A successful Vulkan message or reported frame rate does not prove that the G2 is showing an image. Put the headset on and check both eyes, head rotation, positional movement, audio, and controllers.

Controller bring-up is separate

For the G2 controllers, pairing and tracking are two different things. Pair both controllers to the computer in Mint’s Bluetooth settings, turn both on, and make sure they show as connected before starting or restarting Monado.

  1. Check the batteries, then hold the Windows button on a controller for about two seconds.
  2. Remove the battery cover and press the small pairing button near the wrist strap.
  3. When the controller lights flash in pairing mode, choose it in System Settings → Bluetooth. Repeat for the other controller.
  4. Turn both controllers on and confirm they show as connected.
  5. Restart Monado so it can discover the controllers at startup:
systemctl --user restart monado.service

Then run hello_xr again and check whether the controller buttons/sticks respond. If they appear but do not move through space, that is expected with the basic path: controller input/IMU and camera-based controller position tracking are separate features.

Important: Monado’s WMR controller support historically only discovers controllers that are online when it starts. If they were paired afterward, restart Monado rather than reinstalling everything.

First milestone: headset basics

If the first two checks pass, the core headset path is working. The G2 can show an image and report rotational movement even when camera-based position tracking and controllers are not configured yet.

Current status if only the first two are checked: the display and IMU are working. Do not chase Steam games yet if the goal is room-scale VR; next we need to enable and diagnose Basalt camera tracking, then handle controller pairing/tracking separately.

3. Bring in Steam games

Install Steam and Proton

sudo apt install steam

In Steam, open the game’s Properties → Compatibility page and enable Force the use of a specific Steam Play compatibility tool. Start with the Proton version Steam recommends.

For OpenXR-native games

  1. Start Monado.
  2. Confirm the headset works in hello_xr or another OpenXR test.
  3. Launch the game from Steam.
  4. Select OpenXR in the game’s VR settings if it offers a choice.

For games that require SteamVR

There are two routes. Test only one at a time.

Monado SteamVR plugin

Some Monado packages install a driver that can be registered with SteamVR. The exact install path varies, so use Monado’s current instructions rather than guessing a path.

Open plugin instructions →

xrizer

xrizer translates OpenVR calls to OpenXR, allowing Monado to handle the headset. It is a useful fallback when SteamVR itself cannot acquire the display.

See the current G2 procedure →
Do not troubleshoot the game and the headset at the same time. First prove the headset with a simple OpenXR test. Then test one Steam game. Then add the SteamVR compatibility layer only if that game needs it.

4. Common problems

USB devices are missing

Reseat the headset cable, try a rear motherboard USB port, avoid a hub, and check the powered breakout box. Software cannot fix a missing USB enumeration.

USB works but the headset is black

On NVIDIA this may be a DRM/direct-mode or EDID problem. Check:

xrandr --query
dmesg | grep -Ei 'drm|nvidia|amdgpu|displayport|usb'
60 Hz works but 90 Hz is black

Keep using 60 Hz while diagnosing. The G2 has had NVIDIA EDID and color-depth issues at native 90 Hz. Recent community fixes exist, but rebuilding NVIDIA components should be an advanced, separate project.

Audio is missing
sudo apt install pavucontrol
pactl list short sinks

Choose the Reverb G2 output in Mint’s sound settings or in pavucontrol.

Game opens on the monitor

Start Monado first, verify the active OpenXR runtime, make sure Proton is enabled for the game, and close any stale SteamVR session before trying again.
